# Interactive Calculator & Unit Converter

## Project Description
The Interactive Calculator & Unit Converter is a beginner-friendly command-line application developed using Python. It performs basic mathematical calculations and converts units based on user input. The program uses a menu-driven approach and continues running until the user chooses to exit.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Kilometres to Miles conversion
- Celsius to Fahrenheit conversion
- Input validation using while loops
- Error handling using try-except
- Repeated menu display until the user exits

## Unit Conversions Added
1. Kilometres to Miles
   - 1 km = 0.621371 miles
2. Celsius to Fahrenheit
   - Formula: (°C × 9/5) + 32

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

```bash
python calculator.py
```

## Project Objective
To improve Python programming fundamentals, logical thinking, problem-solving skills, and input validation through a practical beginner-friendly project.
